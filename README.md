# 安元グループ 研究室サイト（Yasumoto Group）

北里大学 海洋生命科学部 生物化学研究室 安元グループの研究室ウェブサイト。
静的サイト（HTML / CSS / JS）。1ファイル構成 `index.html` ＋ `assets/`。

## デザイン
- **ダーク・シネマティック**（濃紺 #051a27 ＋ シアン発光 #00e5ff ＋ 白文字、ガラス調カード）
- **全面動画基調**：トップ＝フルスクリーン動画ヒーロー（7本クロスフェード・5秒間隔）。About/連絡先/中間キャッチも動画背景帯
- ヘッダーは**完全透過**（文字のみ・スクロールで不透明化はオフ）
- 日英バイリンガル（右上 JP/EN トグル、`data-lang-jp` / `data-lang-en`）

## セクション構成
1. ヒーロー（動画7本）

4. 研究内容（全7テーマ）

   2. ポリアミンによるCO2捕捉と生体内炭素輸送（坂田＝陸上植物）／GA図
   3. 陸域リン酸負荷とサンゴ礁保全（SEMリン酸処理図）
   4. 陸域地下水とサンゴ礁（井戸調査写真／細野ら）
   5. サンゴ礁の保全・再生とモニタリング（ERCA推進費・環境省協議会）
   6. CO2鉱物化と海洋炭素循環（マリンホワイトカーボン／AICaS）
   7. 海洋天然物と感染症制御（イノエコ・オンナミド）
5. 現地調査ギャラリー（8枚：ワンギ/Fiji/石西礁湖、ダイバー計測・地下水井戸など人物カット）
6. フィールドノート（4記事）

8. 学会・社会活動（社会活動／受賞／所属学会＋獲得研究費＋指導学生の受賞）
9. 関連リンク・紹介サイト（researchmap/KAKEN/AICaS/地球研/炭酸塩生物学/CRF/BCBC等）
10. メンバー（安元 剛・経歴）／連絡先
